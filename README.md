# Novel Hub

A static book catalog demo with genre shelves, local demo sign-in, likes, and comments.

## Open locally

Open `index.html` in a browser. Sign-in, likes, and comments are stored in that browser only; there is no server or shared account system.

## Shareable copy

This folder intentionally excludes book PDFs. The catalog cards do not open PDF files. Only add books, images, and other materials that you created or have permission to share.
